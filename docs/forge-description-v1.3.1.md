SPT 4.1.4 tester featuring A-10 strafes, double passes, UH-60 extraction and
cargo transfer, and UAV reconnaissance through the TerraGroup TSC Uplink.

This update corrects A-10 aim using EFT's native gravity and drag simulation,
keeps the confirmed laser target through dispatch, and accounts for projectile
travel in impact replay. See the v1.3.1 release notes for test status; in-raid
solo and multiplayer acceptance remains pending.
