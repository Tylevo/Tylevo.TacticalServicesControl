Status: **prepared and unpublished**. TSC v1.3.11 requires standalone
UnityToolkit 2.0.2 and WTT CommonLib 3.0.6. This record concerns that exact
pair; earlier TSC 1.3.10 local feedback and automated results are historical.

The maintainer previously reported successful local use of TSC 1.3.10 with
the older Toolkit rebuild on SPT 4.1.5. That report did not list individual
service checks and does not validate the newly versioned pair.

has not been tested. See [known issues](../known-issues.md) and the
