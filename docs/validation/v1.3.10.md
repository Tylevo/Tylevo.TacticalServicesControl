# v1.3.10 / SPT 4.1.5 candidate validation

Recorded September 5, 2026. This is an unreleased candidate. The maintainer
reports successful initial local use on SPT 4.1.5. Individual service and raid
checks were not listed, and multiplayer on the current SPT/Fika versions
remains untested.

## Build and automated checks

- CI-safe verification passed, including all 238 C# regression tests and
  the dashboard JavaScript checks.
- The complete `SPT-4.1 Release` build passed against the isolated SPT 4.1.5
  references, with four existing warnings and no errors. All four TSC DLLs
  were checked for the matching 1.3.10 version and source revision.
- Reference preparation verified all 42 required reference files and all
  five critical dependency pins. The [port log](../port/SPT-4.1.5-PORT-LOG.md)
  records the official archive, source commits, versions, and hashes.
- Builds keep automatic deployment disabled. Release packaging separately
  requires a clean source revision, matching external build evidence, and
  the exact package allowlist. Generated package evidence records the final
  revision and file hashes.

## Isolated server checks

The first 4.1.5 server smoke used TSC
`1.3.10+691d4a85627359442be4878e0e603e46080ee025`, with server DLL SHA-256
`FAB27DB278F8C8F5233EF2E5A100B207D5F401570D717367B479B5F339772A89`.
Later documentation-only revisions receive a new matched build identity.

The clean official SPT 4.1.5 runtime loaded TSC 1.3.10 and WTT CommonLib
3.0.6. The test used fresh isolated state and a separate local port; no
player profiles, live credentials, configuration, or payment ledgers were copied.

All 26 HTTP checks passed:

- SPT health and the reported 4.1.5 version.
- TSC health, public configuration, and configuration schema.
- The SIC home page's TSC link and the native config-editor shell.
- The dashboard HTML, CSS, and JavaScript, checked against their source bytes.
- Registration of both server bundles and their exact served bytes.

This was a read-only endpoint smoke. It did not exercise paid purchases,
native config Apply/Save writes, cargo delivery, or gameplay.

## Local upgrade and remaining acceptance

The in-place SPT update replaced 21 core files. Verification matched all
1,162 unprotected official files and confirmed that 670 existing user and
settings files were unchanged. Core files and saved state were backed up
before replacement; the two customized BepInEx defaults and doorstop settings
were preserved.

The official 4.1.5 prepatch DLL still rejects the original UnityToolkit
plugin's SPT 4.0 reference. The bundled SPT 4.1 rebuild passes that static
version rule. The server fix for older Unity bundles concerns a separate check.

After installing the matched candidate from source revision
`78ae8d75bb672005895a91df444fd24c0a6bc591`, the maintainer reported:
"seems everythings working". This is a successful initial local-use report
for SPT 4.1.5 with TSC 1.3.10 and the bundled UnityToolkit rebuild.

The report did not list separate checks for Pilot and Uplink, phone controls,
A-10 impacts, UH-60 extraction/cargo, or UAV behavior. Those feature checks
remain open for broader validation; no exhaustive raid coverage is claimed.
Fika multiplayer has not been tested.
