# v1.3.9 SIC integration validation

Checked on September 5, 2026 against local SPT 4.1.4 references and an
isolated SPT 4.1.4 server. No player profiles were copied into that server.

- Full solution build passed with deployment disabled: all four runtime
  assemblies, zero errors, and four existing warnings (two nullable fields
  in the regression build and two obsolete EFT inventory calls).
- 238 C# regression checks and seven dashboard interaction tests passed.
  The new tests exercise separate runtime/disk edits, concurrent revisions,
  failed writes, strict reloads, bounded Windows file-lock retries, and
  retention of unsaved dashboard inputs.
- 14 integration checks passed through SPT 4.1.4's actual
  `ConfigEditorService`, using its config loader and JSON converters. These
  cover TSC selection, snapshots, Apply then Save, Save then Apply, hidden
  disk fields, and stale-write rejection. Only logging and unused profile
  helpers were substituted.
- 13 HTTP checks passed on the isolated running server. SIC's home rendered
  the named `/tsc/admin` link; all three dashboard files matched the installed
  files; `/configs` served its startup page. Config saves, HTTP 409 conflicts,
  invalid edits, malformed reloads, valid reloads, and restoration of the
  isolated settings passed.

An earlier running-server check encountered Windows error 1175 while
replacing a recently accessed config. Active settings and the existing file
were preserved. The final code retries documented file-lock failures for up
to 300 ms in total; it does not retry ambiguous partial replacement errors.
See [Microsoft's ReplaceFile documentation](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew).

The theme diff only adds a divider above the SIC navigation, using the
existing color variable. Existing layout and palette rules are unchanged.
Desktop visual verification was not completed: computer-use stopped because
it could not reliably determine the active browser URL. The HTTP and DOM
tests do not replace a visual check in the launcher.

Fika multiplayer remains untested on the current SPT/Fika versions. This
update does not add a multiplayer compatibility claim or new raid acceptance.
Package and installation hashes are kept in external build evidence so they
can identify the exact clean source commit without changing it afterward.
