# v1.3.12 / SPT 4.1.5 validation scope

Version 1.3.12 is the phone movement and cargo grid patch over the published
1.3.11 source. Pilot Services, purchase history, and quest behavior carry
forward. The optional add-on receives a matching 1.3.12 version manifest.

## Verified before release packaging

- The phone/cargo candidate built against SPT 4.1.5 with deployment disabled.
- CI passed **305 C# regression tests and 10 dashboard tests**.
- Cargo settings passed **27 checks through SPT 4.1.5's ConfigEditorService**:
  defaults, bounds, serialization, Apply/Save, and stale editor handling.
- After installation with a verified backup, the maintainer accepted the
  phone attachment, walking/turning motion, and purchase sprint zoom on
  September 8, 2026, and authorized publication.

The gameplay-tested candidate still used the 1.3.11 development version.
The release uses 1.3.12 and its own clean source identity. Build and package
evidence sidecars identify the exact release commit, references, four DLL
hashes, both ZIP inventories, and archive hashes; earlier candidate hashes
must not be substituted for those release bytes.

See the [phone validation record](phone-sprint-grip.md) and
[cargo grid validation record](cargo-grid-size.md) for the original checks.
The [1.3.11 validation history](v1.3.11.md) and
[optional questline checks](pilot-questline-addon.md) describe earlier candidates.

## Remaining scope

- Native cargo screens with custom dimensions, scrolling at the maximum,
  submitted-item retention, and delivery require gameplay verification.
- Phone acceptance covers the maintainer's local setup. Unrecorded launch
  modes, different clothing, death/raid-end cleanup, interrupted transitions,
  and other matrix cases remain open.
- Current Fika multiplayer is untested. Cargo restrictions and the optional
  questline's existing gameplay limits remain unchanged.

Publishing a public beta does not close these unrecorded checks. See the
[known issues](../known-issues.md) for the service and multiplayer limits.
