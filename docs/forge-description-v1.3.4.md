cargo transfer, and UAV reconnaissance through the TerraGroup TSC Uplink.

selectable cards, a selected-service summary, and a refreshed purchase
confirmation. The store fits the available menu canvas and retains the
existing stash payment and purchase recovery flows.

Native in-raid phone screens, hold-Alt selection, eased zoom, and the A-10
targeting corrections are retained. See [the v1.3.4 release notes](release-notes-v1.3.4.md)
for scope and acceptance checks. Build and package results are recorded in
the candidate's external evidence sidecars.
