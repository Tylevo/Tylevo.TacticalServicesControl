# Tylevo's Tactical Services Control v1.3.3

SPT 4.1.4 tester featuring A-10 strafes and double passes, UH-60 extraction and
cargo transfer, and UAV reconnaissance through the TerraGroup TSC Uplink.

This update adds native phone purchase screens with service artwork, current
prices and balances, and hold-Alt mouse selection. Purchase browsing remains
landscape until the existing portrait confirmation swipe. The eased phone
zoom and A-10 targeting corrections from the previous testers are retained.

See [the v1.3.3 release notes](release-notes-v1.3.3.md) for controls and the
remaining in-game acceptance checks. Build and package results are recorded
in the candidate's external evidence sidecars.
