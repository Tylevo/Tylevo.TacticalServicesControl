SPT 4.1.2 public-beta tester with optional Tylevo Seasonal Modifiers support.

The new Danger Close bridge schedules neutral, host-authoritative ambient A-10
passes without changing TSC's normal standalone behavior. During that global,
manual A-10 Strafe and Double Pass calls are visibly locked; UAV and UH-60
services remain available. Seasonal Modifiers is optional, and missing or
incompatible bridge versions fail closed.

This is a tester candidate. Live raid and Fika acceptance are still required.
