# Tylevo's Tactical Services Control v1.3.5

> **Historical documentation.** These instructions and results describe this
> earlier version. For the prepared TSC v1.3.11 / SPT 4.1.5 update, use the
> [release notes](release-notes-v1.3.11.md) and [installation guide](dependencies.md).
> TSC v1.3.11 requires standalone UnityToolkit 2.0.2; both new packages are
> unpublished. See the [archive index](archive/README.md) for older availability.

SPT 4.1.4 tester featuring A-10 strafes and double passes, UH-60 extraction
and cargo transfer, and UAV reconnaissance through the TerraGroup TSC Uplink.

This update brings the supplied tactical icon pack to the pre-raid store and
native phone. The new artwork uses stronger silhouettes, ivory, amber, and
olive accents, and dark rounded tiles. Extraction and Cargo Transfer use
distinct pickup and sling-load helicopter symbols.

Runtime behavior and layouts are unchanged. See
[the v1.3.5 release notes](release-notes-v1.3.5.md) for installation and scope.
Build, asset, and package results are recorded in the candidate's external
evidence sidecars.
