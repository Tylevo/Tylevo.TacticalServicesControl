# Tylevo's Tactical Services Control v1.3.2

SPT 4.1.4 tester featuring A-10 strafes and double passes, UH-60 extraction and
cargo transfer, and UAV reconnaissance through the TerraGroup TSC Uplink.

This update adds an eased incoming authorization-phone zoom with configurable
F12 timings and preserves the original raid FOV when closing or quickly
reopening the phone. Deploy and radar presentation keep their existing
behavior. The v1.3.1 native-ballistics A-10 correction is retained.

The proposed native purchase interface remains a concept preview and is not
included. The regression suite passes 198/198 tests. Build and package results
are recorded in the candidate's external evidence sidecars; in-game phone
acceptance remains pending. See [the v1.3.2 release notes](release-notes-v1.3.2.md).
